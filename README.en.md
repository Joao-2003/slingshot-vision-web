# Slingshot Vision

[🇧🇷 Português](README.md) | 🇺🇸 English

A slingshot game that runs right in the browser and can be played **with your hand, through the webcam**. It is the web version of my Python computer vision game ([Angry_Birds_Computer_Vision_Python](https://github.com/Joao-2003/Angry_Birds_Computer_Vision_Python)), rewritten in JavaScript with the same sprites, soundtrack and sound effects as the original.

**▶ Play:** https://joao-2003.github.io/slingshot-vision-web/

![Gameplay](docs/gameplay.png)

## How to play

| Control | How |
|---|---|
| Hand (webcam) | Click **📷 Câmera**, pinch thumb and index finger to grab the slingshot, move your hand to aim and open your fingers to launch |
| Mouse or touch | Press near the slingshot, pull and release |
| Keyboard | `P` pause, `R` restart, `S` low gravity, `W` right wall, `C` camera |

Knock out the pigs with as few birds as possible: each pig is worth 10,000 points, each broken wooden piece 5,000 and every bird left over adds a bonus. Levels 1 to 14 are the same as in the original game; from level 15 on, each level is generated by combining two base levels with random character sizes.

## From Python to the web

| Python (original) | Web |
|---|---|
| Pygame | Canvas 2D |
| Pymunk (Chipmunk2D) | [Chipmunk2D in JavaScript](https://github.com/josephg/Chipmunk-js), the same engine |
| OpenCV + MediaPipe Hands | [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) (HandLandmarker, running in the browser through WebAssembly) |
| Sprites and sounds in `resources/` | The same files in `assets/` (background, slingshot, bird, pig, wood, stars, soundtrack and effects); if any fails to load, the game falls back to vector drawing and Web Audio |

### Same physics as the original
Pymunk is a Python binding for Chipmunk2D, so the web version uses Chipmunk2D's own JavaScript port rather than a different engine:
- Same masses, moments of inertia (1000 for the wooden pieces), gravity (700 px/s²), elasticity (0.95), friction, launch impulse (distance × 53) and damage thresholds (1100 and 700, from the contact's `total_impulse`).
- Same fixed 0.01 s step as `update_physics()`; the bird bounces and rolls on the ground exactly like in Pymunk.
- Each level starts from the state Pymunk leaves the `Level.py` pieces in after settling (`tools/export_levels.py`), because the JavaScript port (Chipmunk 6.1) separates overlapping pieces more abruptly than the Chipmunk 7 used by Pymunk. For the same reason the solver runs 20 iterations instead of 10.

Pinch detection follows the logic of `Vision.py`: the distance between the thumb and index fingertips, relative to the hand's size, must stay under a threshold for at least 200 ms. Camera frames are processed in the browser and never leave the computer.

## Design patterns

The same architecture as the original project, which was the subject of my Software Engineering capstone:

| Pattern | Where |
|---|---|
| **State** | `src/states/`: playing, paused, level cleared and level failed |
| **Observer** | `src/observer/`: `Subject` forwards events to `GravityObserver` and `WallObserver` |
| **Abstract Factory** | `src/factories/CharacterFactory.js`: `BirdFactory` and `PestFactory` |
| **Strategy** | `src/characters/Size.js`: `SmallSize`, `NormalSize` and `BigSize` define mass, radius and life |
| **Facade** | `src/GameFacade.js`: builds the game and registers the observers behind `start()` |

## Run locally

JavaScript modules need an HTTP server (and the camera requires `localhost` or HTTPS):

```bash
python -m http.server 8000
# open http://localhost:8000
```
